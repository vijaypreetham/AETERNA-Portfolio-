# AETERNA Portfolio — refreshed edition

A responsive single-file portfolio with a cinematic dark/blue dimensional visual style, services, concept work, process, about, feedback form, and project enquiry form.

## Before publishing: connect Formspree

1. Open https://formspree.io/register and register/sign in using **info.aeternawebsites@gmail.com**.
2. Verify the email if requested.
3. In Formspree, create a **New Form** and set the notification/recipient email to **info.aeternawebsites@gmail.com**.
4. Copy the form endpoint from its Integration page. It will look like `https://formspree.io/f/xxxxxxxx`.
5. Open `index.html` and replace both instances of `https://formspree.io/f/xgaojonl` with your real endpoint.
6. Save the file, then publish it to the root of your GitHub Pages repository.
7. Test both the project enquiry and feedback forms. Confirm the notification arrives in the new inbox (check spam too).

The old phone number has been removed. Contact email is now info.aeternawebsites@gmail.com.

Note: The project tiles are explicitly concept projects, not claimed client commissions. Feedback is collected privately and is not shown as public testimonials automatically. A Formspree form sends submissions to the account notification email; it does not automatically publish visitors’ feedback onto the public website. Public display of submitted feedback needs a database/backend and moderation/consent workflow.
